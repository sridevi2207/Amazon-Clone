# Amazon Clone

A front-end e-commerce website that replicates the core look and
functionalities of Amazon, built using HTML, CSS, and JavaScript.


## About the Project
This project is a clone of the Amazon e-commerce platform, developed
as part of my front-end development learning journey. It focuses on
replicating the UI/UX design, product listing, and navigation
structure of the original Amazon website.

## Features
- Home page with banner and product sections
- Product listing with category-based navigation
- Interactive shopping cart functionality
- Fully responsive UI for mobile and desktop
- Search bar with navigation header
- Clean and pixel-perfect Amazon-inspired design


## Tech Stack
| Technology | Usage |
|---|---|
| HTML | Page structure and layout |
| CSS | Styling and responsiveness |
| JavaScript | Interactive functionality |

## How to Run
1. Clone the repository
   git clone https://github.com/sridevi2207/Amazon-Clone.git

2. Navigate to the project folder
   cd Amazon-Clone

3. Open index.html in your browser
   Double-click index.html or use Live Server in VS Code
